# 01 — Variables y operaciones básicas en Java

## Objetivo
Practicar la declaración de variables, los tipos de datos (`int`, `double`, `char`, `boolean` y `String`), las operaciones aritméticas, la entrada de datos con `Scanner` y la resolución de problemas paso a paso.

**Instrucciones:** resuelve cada ejercicio en su archivo `EjercicioXX.java`. Utiliza `Scanner` cuando se soliciten datos al usuario. No copies soluciones: piensa primero qué datos necesitas, qué operaciones realizarás y qué resultado debes mostrar.

## Nivel 1 — Fundamentos

### Ejercicio 01 — Presentación
Declara variables para almacenar un nombre, una edad y una ciudad. Muestra una frase que incluya los tres datos. **No uses datos personales reales si vas a publicar el código.**

### Ejercicio 02 — Operaciones con dos números
Solicita dos números enteros y muestra su suma, resta, multiplicación y división. Para la división, muestra un resultado decimal y contempla el caso de que el divisor sea cero.

### Ejercicio 03 — Intercambio de variables
Declara dos variables enteras con valores diferentes. Intercambia sus valores utilizando una tercera variable y muestra los valores antes y después.

## Nivel 2 — Conversiones

### Ejercicio 04 — Celsius a Fahrenheit
Pide una temperatura en grados Celsius y conviértela a Fahrenheit mediante la fórmula `F = C × 9 / 5 + 32`. Muestra el resultado con su unidad.

### Ejercicio 05 — Minutos a horas y minutos
Pide una cantidad entera de minutos y calcula cuántas horas completas y minutos restantes representa. Ejemplo: `135` minutos equivalen a `2` horas y `15` minutos.

### Ejercicio 06 — Euros en monedas
Pide una cantidad entera de céntimos y calcula cuántas monedas de 2 €, 1 €, 50 c, 20 c, 10 c, 5 c, 2 c y 1 c se necesitan, utilizando la menor cantidad posible de monedas.

## Nivel 3 — Cálculos combinados

### Ejercicio 07 — Área y perímetro
Solicita la base y la altura de un rectángulo. Calcula y muestra su área y perímetro.

### Ejercicio 08 — Media de tres notas
Pide tres notas decimales y calcula su media aritmética. Muestra el resultado con dos decimales.

### Ejercicio 09 — Segundos a horas, minutos y segundos
Pide una cantidad entera de segundos y conviértela en horas, minutos y segundos restantes. Ejemplo: `3675` segundos equivalen a `1` hora, `1` minuto y `15` segundos.

## Nivel 4 — Reto de examen

### Ejercicio 10 — Ticket de compra
Solicita el precio unitario de un producto y la cantidad comprada. Calcula el subtotal, el IVA del 21 % y el precio final. Muestra un ticket con todos los importes, expresados con dos decimales.

## Método de trabajo
1. Identifica los **datos de entrada**.
2. Decide qué **variables y tipos** necesitas.
3. Escribe las **operaciones** en papel o como comentarios.
4. Programa la solución sin consultar código anterior.
5. Prueba con varios valores y revisa los resultados.

> **Meta:** comprender cada operación y ser capaz de resolver ejercicios nuevos sin memorizar soluciones.
