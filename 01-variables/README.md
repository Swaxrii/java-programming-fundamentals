# 01 — Variables y operaciones básicas

## Objetivo

Aprender los fundamentos de Java mediante ejercicios prácticos de dificultad progresiva.

**Conceptos que se trabajan:**
- Declaración y asignación de variables.
- Tipos de datos: `int`, `double`, `char`, `boolean` y `String`.
- Operadores aritméticos: `+`, `-`, `*`, `/` y `%`.
- Entrada de datos mediante `Scanner`.
- Conversión de tipos de datos.
- Salida de información por consola.

**Restricción:** No utilizar condicionales ni bucles en este bloque.

## Nivel 1 — Fundamentos

### Ejercicio 01 — Presentación
**Scanner:** No.

Declara tres variables para almacenar un nombre, una edad y una ciudad. Muestra una frase que contenga los tres valores.

### Ejercicio 02 — Operaciones matemáticas
**Scanner:** Sí.

Solicita dos números enteros y calcula su suma, resta, multiplicación y división. La división debe mostrar un resultado decimal.

Considera que el segundo número siempre será distinto de cero.

### Ejercicio 03 — Intercambio de variables
**Scanner:** No.

Declara dos variables enteras con valores diferentes. Intercambia sus valores utilizando una tercera variable y muestra los resultados antes y después del intercambio.

## Nivel 2 — Conversiones

### Ejercicio 04 — Conversión de temperatura
**Scanner:** Sí.

Solicita una temperatura en grados Celsius y conviértela a Fahrenheit.

**Fórmula:** `F = C * 9 / 5 + 32`

### Ejercicio 05 — Conversión de minutos
**Scanner:** Sí.

Solicita una cantidad entera de minutos y calcula cuántas horas completas y minutos restantes representa.

### Ejercicio 06 — Descomposición de monedas
**Scanner:** Sí.

Solicita una cantidad entera de céntimos y calcula el número mínimo de monedas necesarias para representarla.

Utiliza las denominaciones de 200, 100, 50, 20, 10, 5, 2 y 1 céntimos.

## Nivel 3 — Cálculos combinados

### Ejercicio 07 — Área y perímetro
**Scanner:** Sí.

Solicita la base y la altura de un rectángulo. Calcula y muestra su área y perímetro.

### Ejercicio 08 — Media de tres notas
**Scanner:** Sí.

Solicita tres notas decimales, calcula su media aritmética y muestra el resultado con dos decimales.

### Ejercicio 09 — Conversión de segundos
**Scanner:** Sí.

Solicita una cantidad entera de segundos y conviértela en horas, minutos y segundos restantes.

## Nivel 4 — Reto final

### Ejercicio 10 — Ticket de compra
**Scanner:** Sí.

Desarrolla un programa que solicite el precio unitario de un producto y la cantidad comprada.

Calcula y muestra:
- Subtotal sin impuestos.
- IVA aplicado (21 %).
- Precio total con impuestos.

Presenta los importes con dos decimales y un formato de ticket.

## Metodología

1. Leer y comprender el enunciado.
2. Identificar las variables y los tipos de datos necesarios.
3. Determinar las operaciones que debe realizar el programa.
4. Implementar la solución de forma independiente.
5. Ejecutar el programa y comprobar los resultados.

Cada ejercicio debe desarrollarse en un archivo independiente con el formato `EjercicioXX.java`.
